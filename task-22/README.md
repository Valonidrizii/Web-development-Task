# Detyra 22 — Galeri e qasshme

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-22/`.

## Çfarë ushtron kodi
CSS Grid, figure/figcaption, alt përshkrues dhe aspect-ratio me object-fit.

## Kontrollet për demonstrim
Të gjashtë imazhet janë lokale. Në 375px shfaqen në një kolonë; në 1280px në tri. Titrat qëndrojnë poshtë imazhit.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
