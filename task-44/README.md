# Detyra 44 — Gjurmues shpenzimesh

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-44/`.

## Çfarë ushtron kodi
Array, reduce për totalin, ID për fshirje dhe shuma të plota në cent. Lista është vetëm në memorie.

## Kontrollet për demonstrim
12.50 + 7.50 = 20.00. Fshirja përditëson totalin. Refuzohen përshkrimi bosh, zero dhe shuma negative. Filtri etiketon totalin e dukshëm.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
