## Konceptet e ushtruara

HTML semantik, tabela, formularë me validim të shfletuesit, CSS box model, Flexbox, Grid, media queries, ngjarje JavaScript dhe përditësimi i DOM-it.

## Probleme të njohura

- Task 01 referon `style.css`, ndërsa skedari ekzistues quhet `style 01.css`.
- Task 05 ka një lidhje drejt `details.html`; kjo faqe ende nuk është krijuar.
- Formulari i kontaktit është demonstrim dhe nuk dërgon email.

Për kontroll vizual, provo faqet në gjerësi 375px dhe 1280px, si edhe navigimin me tastierë.
