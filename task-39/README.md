# Detyra 39 — Tabela e produkteve

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-39/`.

## Çfarë ushtron kodi
Kopjimi i array para sort, krahasimi numerik, localeCompare dhe ID për barazimet.

## Kontrollet për demonstrim
Çmimet në rritje: 2, 5, 5, 12.50, 29.90, 100. Drejtimi shfaqet me tekst dhe aria-sort.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
