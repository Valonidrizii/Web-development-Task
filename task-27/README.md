# Detyra 27 — Artikull me menu ngjitëse

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-27/`.

## Çfarë ushtron kodi
position: sticky brenda kontejnerit, rrjedha normale në mobile dhe scroll-margin-top.

## Kontrollet për demonstrim
Kliko secilën lidhje; në desktop menuja qëndron e dukshme, në mobile shfaqet para artikullit.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
