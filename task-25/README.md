# Detyra 25 — Koleksion butonash

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-25/`.

## Çfarë ushtron kodi
Variablat CSS, :hover, :focus-visible, :disabled dhe animacioni i pritjes.

## Kontrollet për demonstrim
Butonat disabled nuk marrin fokus dhe nuk klikohen. Loading përmban tekst. Provo hover dhe Tab.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
