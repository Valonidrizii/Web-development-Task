# Detyra 50 — Tabelë me tastierë

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-50/`.

## Çfarë ushtron kodi
keydown në elementin e fokusuar, preventDefault vetëm për shigjeta dhe kufizim brenda 0–4.

## Kontrollet për demonstrim
Ka 25 qeliza dhe një aktive. Shigjetat nuk kalojnë skajet dhe nuk kapen jashtë tabelës. Reset kthen 1,1. Në 5,5 shfaqet mesazh.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
