# Detyra 48 — Parapamje imazhi

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-48/`.

## Çfarë ushtron kodi
File API, validimi i tipit/madhësisë, createObjectURL dhe revokeObjectURL.

## Kontrollet për demonstrim
JPEG/PNG i vogël jep parapamje, emër dhe madhësi. Tekst ose >2MB refuzohet. Pastro largon src dhe reseton input. Asnjë upload.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.
