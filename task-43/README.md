# Detyra 43 — Menaxheri i lidhjeve

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-43/`.

## Çfarë ushtron kodi
URL constructor, lista e protokolleve të lejuara, normalizimi, dublikatat dhe ruajtja lokale.

## Kontrollet për demonstrim
Refuzo javascript:, data:, ftp: dhe adresë të pavlefshme. HTTPS://EXAMPLE.COM normalizohet dhe refuzohet kur https://example.com/ ekziston. Titulli HTML shfaqet si tekst.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
