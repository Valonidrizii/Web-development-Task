# Detyra 49 — Shikues JSON

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-49/`.

## Çfarë ushtron kodi
JSON.parse brenda try/catch, JSON.stringify me indentim dhe textContent në pre.

## Kontrollet për demonstrim
Objekti dhe array formatohen. JSON i pavlefshëm jep gabim të lexueshëm; input bosh ka mesazh të veçantë. HTML brenda JSON nuk interpretohet.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
