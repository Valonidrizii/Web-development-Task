# Detyra 28 — Seksion prezantues

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-28/`.

## Çfarë ushtron kodi
Flexbox, media queries, ilustrim lokal SVG dhe lidhje drejt seksioneve të së njëjtës faqe.

## Kontrollet për demonstrim
Lidhjet çojnë te Përfitimet dhe Fillo. Teksti dhe imazhi vendosen në një kolonë në celular.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
