# Detyra 24 — Panel me CSS Grid

## Nisja
Hap `index.html` në shfletues. Për ruajtje lokale të qëndrueshme, nis nga dosja kryesore me `python3 -m http.server 8000` dhe hap `http://localhost:8000/task-24/`.

## Çfarë ushtron kodi
CSS Grid me zona, përmbajtje në rrjedhë normale dhe skip link për tastierë.

## Kontrollet për demonstrim
Menuja kalon mbi përmbajtjen në ekran të vogël. Header dhe footer nuk mbulojnë kartat.
Provoje edhe në gjerësi 375px dhe 1280px dhe përdor Tab për të parë fokusin e tastierës.

## Kufizime
Shembull mësimor lokal. Nuk dërgon të dhëna dhe nuk përdor shërbime të jashtme.
